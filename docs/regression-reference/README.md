# Approved regression references

This directory is non-production reference material.

- `approved-preview/` contains QA captures generated from the inherited interactive preview.
- `approved-designs/` contains the approved project screenshots copied from the read-only project source mirror.
- The runnable preview source is preserved at `prototypes/approved-preview` and covered by Playwright.

These files guide visual and interaction regression checks during Milestone 5. They do not define domain semantics, seed production data, or ship as an application route.
